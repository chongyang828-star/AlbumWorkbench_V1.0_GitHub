# AlbumWorkbench（专辑制作工作台）

面向 B 站音乐专辑 / 合集 UP 主的一站式本地轻量桌面工作台。  
**纯 Python 3 标准库 + Tkinter**，无需 `pip install` 任何第三方依赖，双击即用。

## 核心功能

### 顶部公共栏（选一次文件夹，三页共享）
- 支持直接将专辑文件夹拖入窗口，自动读取标签中的**专辑名、歌手、发行日期**。
- **搜 ID / 联网查询**：并发查询 QQ 音乐 + 网易云音乐 + iTunes（自动兼容 Windows 系统代理），一键拿到：
  - **QQ 音乐专辑 ID / 链接** 与 **网易云专辑 ID / 链接**（一键复制给歌词下载器使用）
  - 准确发行日期（`YYYY-MM-DD`）
  - 高清专辑封面、QQ 音乐原版简介与推荐标签
- **置顶歌单条**：弹出迷你置顶悬浮条，只显示去掉后缀的编号歌名，点一下即复制并自动变灰打勾，方便剪辑软件手动贴歌名。

### ① 音频排序 & 封面
- **直接鼠标上下拖动行**调整曲目顺序（双击行可直接输入目标序号）。
- **纯文本曲目表匹配**：从 QQ 音乐 / 网易云网页复制歌单，`Ctrl+V` 粘贴即可模糊匹配排序。
- **安全改名 + 写标签 + 撤销上次**：纯 Python 直接读写 FLAC 元数据（`TITLE` / `ARTIST` / `ALBUM` / `TRACKNUMBER`），两阶段改名防覆盖。
- **封面直存目录**：优先从 FLAC 提取内嵌高清封面，无内嵌时自动联网下载高清原图直存当前专辑目录。
- **片头文案一键复制**：自动按格式拼好 `《专辑名 神专推荐》` 与 `（歌手-YYYY-MM-DD）`。

### ② 歌词合并 SRT
- 自动沿用 ① 的音频顺序与精确时长对齐 `.srt` 歌词，支持拖拽微调顺序。
- **每首歌开头自动插入编号歌名（可勾选）**：在每首歌开头到第一句歌词出现前自动生成一条编号歌名片段；遇到前奏过短或纯音乐无歌词时会在底部日志标 `⚠` 提醒。
- 导出达芬奇 / PR / 剪映通用的 **UTF-8 BOM + CRLF** 合并字幕，并支持同步保存一份副本到自定义歌词目录。

### ③ 时间轴 & 发布辅助
- **精准时间轴**：按音频精确时长自动累加，默认精确到秒（`MM:SS`），可选备用 **精确到帧**（`MM:SS:FF`）；支持全局偏移（默认 `+3` 秒）以及对粘贴进来的外部时间轴一键加减秒数。
- **QQ 音乐专辑简介**：自动拉取纯文本简介，一键复制。
- **专辑强相关推荐标签**：基于歌手、专辑名、网易云歌曲热度、简介关键词生成 6 个高匹配度 B 站标签（支持点击单个复制、复制全部 6 个与「换一批」）。

## 运行方式

1. 确保系统已安装 **Python 3.8+**（Windows 安装时勾选 `Add Python to PATH`）。
2. 直接双击 `启动.bat`，或在终端运行：
   ```bash
   python AlbumWorkbench.py
   ```

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `AlbumWorkbench.py` | 主界面与交互逻辑（Tkinter） |
| `core_audio.py` | 音频扫描、FLAC 元数据/内嵌封面读写、纯文本曲目表匹配、安全改名与撤销 |
| `core_srt.py` | SRT 编码解析与合并、开头自动插歌名、时间轴生成与偏移 |
| `core_online.py` | QQ 音乐 / 网易云 / iTunes 并发查询、代理兼容、专辑标签推荐 |
| `启动.bat` | Windows 一键启动脚本 |

> 提示：如需修改合并字幕的同步备份目录，可调整 `AlbumWorkbench.py` 顶部的 `EXTRA_SRT_DIR` 常量。
